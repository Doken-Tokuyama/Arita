## Goal

Close the **index-based collection mutation** gap without panic or Rust IndexMut: write sugar `m[k] = v` / `v[i] = x` with the **same** semantics as already-IN APIs (`put` ADR-237 · `set` ADR-265/270) and OOB propagation visible in the signature (`fn → Result`, ADR-277/278). Language → emit Rust safe. **NO** Cargo wrapper. **NO** Axum surface. Vertical ≠ GP ceiling. **Do not** reopen Core 0.8 (ADR-276–280) or E0272/E0291/E0340/E0341/E0342/E0343.

## 0.2 Residual IndexMut — non-Map receiver (Vec until 283, String, other types) or no binding → E0314 · compound / nested / field = **E0006**

Every index-assign **not** covered by 282/283 keeps a **decided** reject (no new grammar in 0.9):

| Form | Diag |
|-------|------|
| `v[i] = x` on Vec/List (outside 283’s IN; until 283 moves it to **E0344**) | **E0314** (HIR, span `@a..b`; ADR-282 §0.2) |
| String / Text `s[i] = x` (String.set HOLD; UTF-8 byte/char needs its own ADR) | **E0314** (current oracle `neg-e0310-index-string`) |
| Index-assign on another non-Map type (Int, Bool, Bytes, Option, Result, record, enum, Task…) | **E0314** (HIR `HirStmt::IndexAssign`: every receiver ≠ Map) |
| Unbound target (not a visible variable) `q[k] = v` | **E0314** |
| Compound `m[k] += v` / `v[i] += x` / `-=` / `*=` / … | **E0006** `construct outside F1.1 (parse failure)` |
| Nested `v[i][j] = x` / `m[k][j] = x` | **E0006** |
| Field-on-index `v[i].f = x` / `m[k].f = x` | **E0006** |
| Index outside the v0 form (`int_lit` \| `string_lit` \| `ident`, same as `index_expr` ADR-261/266) | **E0006** (parse failure) |
| Index-assign as an expression (value of `v[i] = x`) | OUT — statement only |

Rule (Architect 2026-09-26, aligned with HIR): non-Map receiver (Vec until 283, String, other types) or no binding → E0314. Compound / nested / field-on-index / index outside v0 form → E0006.

**E0314 SoT note (flag):** ADR-233 pins **E0314** = `unknown field` (HIR record). The parser reuses E0314 for IndexMut (ADR-261/266 “suggested”; `arita-syntax` `index_assign_stmt`). **Preexisting** overload; this vertical neither reassigns nor splits it (anti-collision). Split E0314 → **backlog** (own ADR; see §Backlog).
