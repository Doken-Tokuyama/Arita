## 1. Syntax surface IN (v0.1)

| Area | IN | OUT (for now) |
|------|----|-----------------|
| Units | `module`, `fn`, curated `use` | macros, `include!` |
| Data | `record`, `enum`, exhaustive `match` | deep anonymous tuples, `union` |
| Base types | `Int`, `Bool`, `Text`, `Bytes` | free floats, raw ptr |
| Collections | `List<T>`, `Map<K,V>` (total/fallible APIs) | panicking `[]` sugar, panicking `insert` |
| Errors | `Option`, `Result`, bounded `?` | `unwrap`/`expect` surface |
| Ownership | owned default, `borrow` / `borrow mut`, move | lifetimes on surface, refs in struct/return |
| Effects | typed `Io` / files / JSON / CLI | net/async (Core 0.2 / service profile) |
| Executable spec | `scenario` / `acceptance` | mandatory formal `requires`/`ensures` |
| Concurrency | — | `Mutex`, threads, async |

Indexing: canonical `get`→Option (ADR-085/227). `[]` stays E0310 until sugar GO.

## 2. Emit / policy

- **Deterministic** Rust emit, Cargo workspace  
- `#![forbid(unsafe_code)]` on user crates  
- **Curated** Rust bindings (typed manifest); no open crates.io  
- Default profile `safe`

## 3. Reference program (E2E oracle)

A non-trivial CLI (e.g. `arita-ref-json-cli`): parse JSON file → transform → typed stdout/err → acceptance **scenarios**.  
Measure: compile+run+scenarios+evidence hash. skip ≠ PASS.

- Docs: example + ROADMAP tick Core 0.1  
- **No** insert/`[]`/Mutex on surface
