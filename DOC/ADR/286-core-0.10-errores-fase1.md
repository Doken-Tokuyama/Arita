### 0.0 Estado actual verificado (lectura de fuentes, sin ejecutar)

- **Dónde se emite E0272 hoy:** `crates/arita-hir/src/lib.rs` L1351–1352 (match como expresión) y L3903–3904 (match como sentencia). Se emite **dentro** de la misma pasada de type check (`check_body`), no en un pase aparte. Orden dentro de un `match` sobre `Result`: tipado de patrones (E0223) → tipado de cada brazo (`self.check_body(&arm.body)?`, L3877) → exhaustividad E0270 (L3886) → E0340 si el scrutinee es host-IO / si no, E0272 (L3899–3905) → E0225 (L3906). Diagnóstico único: el primero que falla corta (`?` / `return Err`). Por tanto: un error de tipo **anterior** en orden fuente o **dentro** de los brazos gana a E0272; un error de tipo **posterior** en orden fuente **no** se ve (gana E0272). E0272 **no** se emite con errores de tipo previos presentes.
- **Detector v1:** `result_err_swallowed_stmt` (L4416) = payload no usado (`err_binding_unused_in_body`, L4400) **y** cuerpo teatro (`theater_stmt_body`, L4386: vacío o **una sola** sentencia `lit` / `print(<lit>)` / `assert` de lits; `is_const_lit` incluye `LitStr`, L4226). «Uso» = `stmt_uses_ident` (L4313): un `let` cuyo init lee el binding **cuenta como uso** (L4315).
- **Causa de B-285-4 (doble):** (1) `let _c: Int = e` hace que `e` «se use» (L4315) y (2) el cuerpo tiene 2 sentencias, así que `theater_stmt_body` devuelve `false` (L4390). v2 debe atacar las dos cosas.
- **Host-IO:** si el scrutinee viene de `host.read_text`/`write_text` (directo o vía binding `from_host_io`), E0272 **no** se evalúa y rige E0340 (L3889–3905; L1337–1353). `let _ = host.…` → E0340 (L3617–3620); `host.…` suelto → E0340 (L3640). Consecuencia: los 4 `Err(3)` de ref-mut (scrutinees `rp`/`rd` = `host.read_text`, lib.arita L61/L77) quedan hoy fuera de E0272 por host-IO; D-4 los valida además por P3(ii).

Motivo: `Err(e) => { let _c: Int = e  let v: Int = g()?  Ok(v) }` solo propaga si `g()` falla; si `g()` va bien, `e` se pierde ⇒ **E0272**. La frase «propaga con `?` / return de un `Result`» de arriba vale solo **sin** sumidero. Sin sumidero nada cambia: v1 (P8), y `f()?` sigue siendo uso por P4. |
