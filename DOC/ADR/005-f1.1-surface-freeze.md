## Decisión (F1.1)

### 1. Superficie aceptada (única forma canónica)

```arita
module <ident>

fn main() -> Io<()> {
  print("<lit-str>")
  // cero o más print("...") adicionales
}
```

Reglas:

| Elemento | F1.1 |
|----------|------|
| `module <ident>` | obligatorio; un módulo por archivo |
| `fn main() -> Io<()>` | único `fn` permitido; tipo de retorno **exactamente** `Io<()>` (sintaxis literal) |
| `print("…")` | única sentencia; argumento = **LitStr** (string entre comillas dobles); sin interpolación |
| Comentarios | `//` fin de línea |
| Encoding | UTF-8; keywords ASCII |

AST post-parse: sin cambio — CUT `F1-AST-RICH-20260913` (`Module`/`Function`/`Call`/`LitStr`).

### 2. Códigos de diagnóstico estables `E0xxx`

**Formato canónico (compilador / CLI):** `E0xxx: <English text>` — el texto tras el código es **inglés estable** (IAs). Prosa DOC puede seguir en español.

El **código** no se renumera ni se reutiliza con otra semántica.

| Código | English message (canonical) | Cuándo |
|--------|----------------------------|--------|
| **E0001** | `expected print("...") in main (MVP)` | No usable `print("…")` in `main` (already in spike) |
| **E0002** | `missing module <ident>` | Missing `module` header |
| **E0003** | `missing fn main` | Missing `fn main` or name ≠ `main` |
| **E0004** | `main return type must be Io<()>` | Return type syntax ≠ `Io<()>` |
| **E0005** | `invalid string literal in print` | Unclosed LitStr / bad escape |
| **E0006** | `construct not allowed in F1.1` | Out-of-surface (`let`, other `fn`, `spec`, …); hard-error |
| **E0007** | `illegal ident or keyword misuse` | Bad ident / keyword |
| **E0008** | `empty source` | Empty file / comments only |
| **E0009** | `duplicate module or fn` | More than one `module` or `fn` |
| **E0010** | `print requires a single string literal` | `print` args ≠ one LitStr |

Measure/emit (stable codes; not parse surface):

| Código | English message (canonical) | Cuándo |
|--------|----------------------------|--------|
| **E0100** | `emitted Rust failed rustc` | Emit output rejected by `rustc` |
| **E0101** | `measure skipped` | Suite not run — **skip ≠ PASS** |
| **E0102** | `measure failed` | Test/oracle FAIL |

`E02xx+` = F2 anti-theater / ownership; `E03xx+` = logic island F3. Not assigned in F1.1.

### 3. Fuera de F1.1 (OUT)

Explicitamente **no** en F1.1 (→ E0006 o fase posterior):

- Otros `fn` que no sean `main`; parámetros; returns no-`Io<()>`
- `let`, bindings, tipos user-defined, generics
- Control flow (`if`/`while`/`match`)
- `print` de no-strings; I/O distinto de `print`
- Isla lógica: `spec` / `fact` / `rule` / `query` (F3; ADR-002)
- Ownership / borrow check (F2)
- Anti-theater oráculo (F2 measure)
- HIR, typecheck rico, LSP (F4)
- `unsafe`, macros, FFI
- AST `main_prints` (histórico; no reabrir sin GO + CUT-ID)
- Código / submodule IDNI (ADR-002 / `08-LICENSES`)

### 4. Puente a F2 (no congelado aquí)

F2 añadirá (ADR futuro): move/borrow subset, `Vec`/`String`/print tipado, prohibiciones anti-theater, pack few-shot. **No** cambia el AST CUT rich sin GO.
