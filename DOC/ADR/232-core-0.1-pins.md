## 1. Surface sintaxis IN (v0.1)

| Área | IN | OUT (por ahora) |
|------|----|-----------------|
| Unidades | `module`, `fn`, `use` curado | macros, `include!` |
| Datos | `record`, `enum`, `match` exhaustivo | tuples anónimas profundas, `union` |
| Tipos base | `Int`, `Bool`, `Text`, `Bytes` | floats libres, raw ptr |
| Colecciones | `List<T>`, `Map<K,V>` (APIs totales/fallible) | sugar `[]` panic, `insert` panicking |
| Errores | `Option`, `Result`, `?` acotado | `unwrap`/`expect` surface |
| Ownership | owned default, `borrow` / `borrow mut`, move | lifetimes en surface, refs en struct/return |
| Efectos | `Io` / files / JSON / CLI tipados | net/async (Core 0.2 / perfil service) |
| Spec ejecutable | `scenario` / `acceptance` | `requires`/`ensures` formales obligatorios |
| Concurrencia | — | `Mutex`, threads, async |

Indexación: canónico `get`→Option (ADR-085/227). `[]` sigue E0310 hasta sugar GO.

## 2. Emit / policy

- Emit Rust **determinista**, workspace Cargo  
- `#![forbid(unsafe_code)]` en crates usuario  
- Bindings Rust **curados** (manifiesto tipado); no crates.io abierto  
- Perfil default `safe`

## 3. Programa de referencia (oráculo E2E)

Un CLI no trivial (p.ej. `arita-ref-json-cli`): parse JSON file → transform → stdout/err tipado → **scenarios** acceptance.  
Measure: compile+run+scenarios+evidence hash. skip ≠ PASS.
