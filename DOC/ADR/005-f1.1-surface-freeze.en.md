- **Estado:** **aceptada**

## Context / product scope (<person>)

ARITA = lenguaje **useful for AIs**: clear surface, stable diagnostics, ownership Rust-like, own logic island, emit→Rust multi-OS.

This ADR freezes the **F1.1 linguistic surface** (what an AI may write and which errors it sees), not the AST shape (remains ADR-004).

## Decision (F1.1)

### 1. Accepted surface (sole canonical form)

```arita
module <ident>

fn main() -> Io<()> {
  print("<lit-str>")
  // zero or more additional print("...")
}
```

Reglas:

| Elemento | F1.1 |
|----------|------|
| `module <ident>` | mandatory; one module per file |
| `fn main() -> Io<()>` | unique `fn` allowed; tipo de return **exactamente** `Io<()>` (sintaxis literal) |
| `print("…")` | only statement; argument = **LitStr** (string in double quotes); without interpolation |
| Comments | `//` end of line |
| Encoding | UTF-8; keywords ASCII |

AST post-parse: no change — CUT `F1-AST-RICH-20260913` (`Module`/`Function`/`Call`/`LitStr`).

### 2. Stable diagnostic codes `E0xxx`

**Formato canonical (compilador / CLI):** `E0xxx: <English text>` — el texto after el code es **English stable** (IAs). Prosa DOC may follow en Spanish.

El **code** no se renumera ni se reutiliza with otra semantics.

| Code | English message (canonical) | When |
|--------|----------------------------|--------|
| **E0001** | `expected print("...") in main (MVP)` | No usable `print("…")` in `main` (already in spike) |
| **E0002** | `missing module <ident>` | Missing `module` header |
| **E0003** | `missing fn main` | Missing `fn main` or name ≠ `main` |
| **E0004** | `main return type must be Io<()>` | Return type syntax ≠ `Io<()>` |
| **E0005** | `invalid string literal in print` | Unclosed LitStr / bad escape |
| **E0006** | `construct not allowed in F1.1` | Out-of-surface (`let`, other `fn`, `spec`, …); hard-error |
| **E0007** | `illegal ident or keyword misuse` | Bad ident / keyword |
| **E0008** | `empty source` | Empty file / comments only |
| **E0009** | `duplicate module or fn` | More than one `module` or `fn` |
| **E0010** | `print requires a single string literal` | `print` args ≠ one LitStr |

Measure/emit (stable codes; not parse surface):

| Code | English message (canonical) | When |
|--------|----------------------------|--------|
| **E0100** | `emitted Rust failed rustc` | Emit output rejected by `rustc` |
| **E0101** | `measure skipped` | Suite not run — **skip ≠ PASS** |
| **E0102** | `measure failed` | Test/oracle FAIL |

`E02xx+` = F2 anti-theater / ownership; `E03xx+` = logic island F3. Not assigned in F1.1.

### 3. Fuera de F1.1 (OUT)

Explicitamente **no** en F1.1 (→ E0006 o fase later):

- Other `fn` que no sean `main`; parameters; returns no-`Io<()>`
- `let`, bindings, tipos user-defined, generics
- Control flow (`if`/`while`/`match`)
- `print` de no-strings; I/O distinto de `print`
- Logic island: `spec` / `fact` / `rule` / `query` (F3; ADR-002)
- Ownership / borrow check (F2)
- Anti-theater oracle (F2 measure)
- HIR, typecheck rico, LSP (F4)
- `unsafe`, macros, FFI
- AST `main_prints` (historical; no reabrir without GO + CUT-ID)
- Code / submodule IDNI (ADR-002 / `08-LICENSES`)

### 4. Puente a F2 (no congelado here)

F2 will add (ADR future): move/borrow subset, `Vec`/`String`/print tipado, prohibitions anti-theater, pack few-shot. **No** change el AST CUT rich without GO.
