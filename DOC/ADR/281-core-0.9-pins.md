## Objetivo

Cerrar el gap de **mutación de colecciones por índice** sin panic ni IndexMut Rust: sugar de escritura `m[k] = v` / `v[i] = x` con la **misma** semántica que APIs ya IN (`put` ADR-237 · `set` ADR-265/270) y propagación de OOB visible en la firma (`fn → Result`, ADR-277/278). Language → emit Rust safe. **NO** Cargo wrapper. **NO** Axum surface. Vertical ≠ techo GP. **No** reabrir Core 0.8 (ADR-276–280) ni E0272/E0291/E0340/E0341/E0342/E0343.

## 0.2 IndexMut residual — receptor no-Map (Vec hasta 283, String, otros tipos) o sin binding → E0314 · compuesto / anidado / campo = **E0006**

Todo index-assign **no** cubierto por 282/283 mantiene un rechazo **decidido** (sin gramática nueva en 0.9):

| Forma | Diag |
|-------|------|
| `v[i] = x` sobre Vec/List (fuera del IN de 283; hasta que 283 lo mueva a **E0344**) | **E0314** (HIR, span `@a..b`; ADR-282 §0.2) |
| String / Text `s[i] = x` (String.set HOLD; UTF-8 byte/char requiere ADR propio) | **E0314** (oracle vigente `neg-e0310-index-string`) |
| Index-assign sobre otro tipo no-Map (Int, Bool, Bytes, Option, Result, record, enum, Task…) | **E0314** (HIR `HirStmt::IndexAssign`: todo receptor ≠ Map) |
| Target sin binding (no es variable visible) `q[k] = v` | **E0314** |
| Compuesto `m[k] += v` / `v[i] += x` / `-=` / `*=` / … | **E0006** `construct outside F1.1 (parse failure)` |
| Anidado `v[i][j] = x` / `m[k][j] = x` | **E0006** |
| Campo sobre índice `v[i].f = x` / `m[k].f = x` | **E0006** |
| Índice fuera de la forma v0 (`int_lit` \| `string_lit` \| `ident`, igual que `index_expr` ADR-261/266) | **E0006** (parse failure) |
| Index-assign como expresión (valor de `v[i] = x`) | OUT — solo statement |

Regla (Arquitecto 2026-09-26, alineada con HIR): receptor no-Map (Vec hasta 283, String, otros tipos) o sin binding → E0314. Compuesto / anidado / campo sobre índice / índice fuera de forma v0 → E0006.

**Nota SoT E0314 (flag):** ADR-233 fija **E0314** = `unknown field` (HIR record). El parser reusa E0314 para IndexMut (ADR-261/266 «sugerido»; `arita-syntax` `index_assign_stmt`). Overload **preexistente**; este vertical **no** lo reasigna ni lo separa (anti-colisión). Split E0314 → **backlog** (ADR propio; ver §Backlog).
