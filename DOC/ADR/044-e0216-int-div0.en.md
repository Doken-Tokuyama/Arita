# ADR-044 — E0216 integer division by zero

- **Estado:** **aceptada** + **verified** (Lex measure **84** accepted + **2** gated)
- **CUT-ID:** `TRAPS-INT-DIV0-20260915`
- **Fecha:** 2026-09-15
- **Autores:** ARITA Arquitecto (pins/GO) + Ingeniero Rust (IMPL; sondeo HOLE)
- **Relacionados:** ADR-006 (Int binary `/` `%`), ADR-010 E021x, ADR-022 safe-only
- **Gobernanza:** **aceptada** + **verified** (IMPL). Executor Ingeniero; Parser/Codegen HOLD. Rechazo **HIR antes de emit**; no depender de rustc E0100 ni panic runtime.
- **Barra:** E2E measure neg; skip ≠ PASS.

## Decision (pins GO)

### 1. Code

| Code | Message EN canonical |
|--------|---------------------|
| **E0216** | `integer division by zero` |

Cubre **`/` y `%`** with divisor cero. Overflow `+/-/*` → **ADR-045** / E0217 (no this CUT).

### 2. HIR detection v0

1. `Binary` `/` o `%` with RHS = `LitInt 0` → **E0216**.
2. Call `fn(a: Int, b: Int) -> Int { a / b }` (o `%`) with **2º arg LitInt 0** (p.ej. en `assert`/`test`) → **E0216** (covers fixture neg).
3. OUT v0: const-fold general; divisor “probado cero” no-literal complejo.

### 3. Oracles

**Neg** `ejemplos/f2/neg/e0216-div0.arita` (o path Ingeniero):

```arita
module unchecked_div_neg
fn div(a: Int, b: Int) -> Int { a / b }
fn main() -> Io<()> { print("ok") }
test t_div0 { assert div(10, 0) == 0 }
```

Opc. lit: `let x: Int = 10 / 0` → E0216.

**Clean:** `if b != 0 { … div(10, b) … }` (no E0216).

Nota: `print(10/2)` remains E0006 (surface); usar let/call.

### 4. OUT

- Depender de rustc panic / E0100 as evidence
- Overflow `+/-/*` → **ADR-045** / E0217
- Float (no hay)
