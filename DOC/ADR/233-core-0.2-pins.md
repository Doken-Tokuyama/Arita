## Objetivo

Vertical **service**: IA escribe ARITA → **HTTP daemon** (o equivalente net) Rust real → scenarios de aceptación de red → evidencia JSON. Perfil de compilación default de este vertical: **`service`**.

## 0. Corte decisivo (GO)

| Pin | Decisión |
|-----|----------|
| **Vertical ref** | **HTTP daemon** (`arita-ref-http-echo` o `arita-ref-json-api`) — **no** CLI-only (eso es 0.1) |
| **Perfil** | `service` (timeouts, tamaños, cancelación, TLS *policy* DOC; TLS IMPL puede ser stub/config HOLD) |
| **Async model** | `async fn` / `await` **explícitos** en surface; un runtime curado emitido (p.ej. tokio detrás del binding) — **sin** async implícito tipo “todo es async” |
| **Concurrencia** | tasks/async OK; **`Mutex` / locks compartidos = HOLD** (E0312 / ADR-229) hasta R7 |
| **I/O red** | APIs tipadas `HttpServer` / `HttpRequest` / `HttpResponse` (nombres pin abajo) vía bindings curados — **no** `std::net` libre ni crates.io abierto |
| **Errores** | `Result` + timeouts como `Err` tipado; **prohibido** panic en path feliz; no `unwrap` surface |
| **Programa ref** | Daemon HTTP: ≥1 ruta JSON in/out; graceful shutdown signal; ≥2 scenarios (happy + timeout/4xx); evidence hash |
| **HOLD** | sugar `[]` · insert panic · Mutex · raw sockets · reqwest/hyper sueltos · `arita repair` IMPL |

## 1. Surface sintaxis IN / OUT (v0.2 delta sobre 0.1)

| Área | IN (nuevo o ampliado) | OUT / HOLD |
|------|----------------------|------------|
| Async | `async fn`, `await`, `spawn` curado | async implícito; `block_on` en libs usuario |
| Tiempo | `timeout(ms, async …) -> Result` | sleeps busy-loop theater |
| Net | bindings HTTP server/client JSON curados | TCP/UDP raw; HTTP/2+ multiplexing fancy; WS (0.3) |
| TLS | policy flag + stub/config | PKI full / custom crypto |
| Concurrencia | tasks | `Mutex`, channels libres, threads OS surface |

| Core 0.1 | todo IN de ADR-232 sigue IN | — |

## 2. Emit / policy (`service`)

- Emit Rust determinista + runtime **único** curado (versión pinada en manifiesto)  
- `#![forbid(unsafe_code)]` en crates ARITA usuario; unsafe solo en adapters `ffi` auditados (perfil `ffi`, no este vertical)  
- Caps por default: body ≤ 1 MiB, headers ≤ 64 KiB, idle ≤ 30s (ajustables en manifieto; valores exactos = IMPL note)  
- Bindings allowlist; dep graph reproducible  

## 3. Programa de referencia

`arita-ref-http-json`: listen localhost efímero → `POST /echo` JSON → response tipada; `GET /health`; shutdown limpio.  
Scenarios: echo OK; payload oversize → error tipado; (opcional) cancel.  
Measure: build + run scenarios + evidence hash. skip ≠ PASS.
