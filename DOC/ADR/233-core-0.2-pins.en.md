## Goal

**service** vertical: AI writes ARITA → real-Rust **HTTP daemon** (or net equivalent) → network acceptance scenarios → JSON evidence. Default compile profile for this vertical: **`service`**.

## 0. Decisive cut (GO)

| Pin | Decision |
|-----|----------|
| **Ref vertical** | **HTTP daemon** (`arita-ref-http-echo` or `arita-ref-json-api`) — **not** CLI-only (that is 0.1) |
| **Profile** | `service` (timeouts, sizes, cancellation, TLS *policy* DOC; TLS IMPL may be stub/config HOLD) |
| **Async model** | **Explicit** `async fn` / `await` in surface; one curated emitted runtime (e.g. tokio behind the binding) — **no** implicit async like “everything is async” |
| **Concurrency** | tasks/async OK; **shared `Mutex` / locks = HOLD** (E0312 / ADR-229) until R7 |
| **Net I/O** | Typed `HttpServer` / `HttpRequest` / `HttpResponse` APIs (names pinned below) via curated bindings — **no** free `std::net` or open crates.io |
| **Errors** | `Result` + timeouts as typed `Err`; panic **forbidden** on the happy path; no surface `unwrap` |
| **Ref program** | HTTP daemon: ≥1 JSON in/out route; graceful shutdown signal; ≥2 scenarios (happy + timeout/4xx); evidence hash |
| **HOLD** | sugar `[]` · insert panic · Mutex · raw sockets · reqwest/hyper sueltos · `arita repair` IMPL |

## 1. Syntax surface IN / OUT (v0.2 delta over 0.1)

| Area | IN (new or widened) | OUT / HOLD |
|------|----------------------|------------|
| Async | `async fn`, `await`, curated `spawn` | implicit async; `block_on` in user libs |
| Time | `timeout(ms, async …) -> Result` | busy-loop sleep theater |
| Net | curated HTTP server/client JSON bindings | raw TCP/UDP; fancy HTTP/2+ multiplexing; WS (0.3) |
| TLS | policy flag + stub/config | PKI full / custom crypto |
| Concurrency | tasks | `Mutex`, free channels, OS threads in surface |
| Effects | `Io` + `Net` (or documented extended `Io`) | hidden effects in “pure” |
| Core 0.1 | all ADR-232 IN stays IN | — |

## 2. Emit / policy (`service`)

- Deterministic Rust emit + **one** curated runtime (version pinned in the manifest)  
- `#![forbid(unsafe_code)]` on user ARITA crates; unsafe only in audited `ffi` adapters (`ffi` profile, not this vertical)  
- Default caps: body ≤ 1 MiB, headers ≤ 64 KiB, idle ≤ 30s (adjustable in the manifest; exact values = IMPL note)  
- Binding allowlist; reproducible dep graph  

## 3. Reference program

`arita-ref-http-json`: ephemeral localhost listen → `POST /echo` JSON → typed response; `GET /health`; clean shutdown.  
Scenarios: echo OK; payload oversize → error tipado; (opcional) cancel.  
Measure: build + run scenarios + evidence hash. skip ≠ PASS.
