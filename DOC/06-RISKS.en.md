# Risks

1. **Scope:** a “new language” is multi-year; mitigate with emit-to-Rust (ADR-001).
2. **Logic island:** maturity of the own checker; mitigate with reduced scope in F3 (ADR-002). Temptation to link IDNI: rejected in the MVP (`08-LICENSES-IDNI.md`).
3. **AI adoption:** without grammar/constrained decoding, it will not be more innate than Rust.
4. **Theater in ARITA:** if measure is weak, AIs will lie the same way; phase F1→F2→F3 and **skip ≠ PASS**.
5. **IDNI licenses:** do not copy/redistribute IDNI code; semantic inspiration OK without linking (`08-LICENSES-IDNI.md`).
6. **Name/path:** active work in `<repo>`; Lexar copy in `<repo-mirror>` — manual sync if both exist. Do not confuse with “antivirus”.
